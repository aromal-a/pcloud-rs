# `pcloud-cli`

**Maturity:** Evolving product surface

**Version:** `0.8.1-beta`

**Directory:** `crates/pcloud-cli`

**Manifest:** [`crates/pcloud-cli/Cargo.toml`](https://github.com/ezechiel203/pcloud-rs/blob/main/crates/pcloud-cli/Cargo.toml)

Command-line client (pcloudc) for pcloud-rs that talks to the local daemon over secure IPC.

## Feature-family profile

**Why it exists.** Expose daemon capabilities to humans and automation without duplicating remote or security logic in a short-lived process.

**What it is good for.** Login, status, file operations, sync, backup, Crypto, account administration, diagnostics, migration, JSON output, and shell completion.

**Why it is good at that job.** Typed IPC commands, stable exit codes, field selection, redacted prompts, and machine-readable output serve both operators and scripts.

# `pcloud-crypto`

**Maturity:** Internal stable

**Version:** `0.1.0`

**Directory:** `crates/pcloud-crypto`

**Manifest:** [`crates/pcloud-crypto/Cargo.toml`](https://github.com/ezechiel203/pcloud-rs/blob/main/crates/pcloud-crypto/Cargo.toml)

Client-side crypto folder primitives (AES-256-GCM, Argon2, zeroized keys) for pcloud-rs.

## Feature-family profile

**Why it exists.** Provide client-side Crypto-folder confidentiality while supporting both official-client interoperability and a Rust-native hardened format.

**What it is good for.** Content and filename encryption, key derivation/wrapping, unlock lifecycle, password rotation, crypto sharing, policy, and compatibility KATs.

**Why it is good at that job.** Domain-separated keys, zeroized secret material, authenticated sectors, nonce budgets, lockout, and explicit backend identity avoid silent format or key misuse.

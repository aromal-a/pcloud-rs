# `pcloud-config`

**Maturity:** Evolving product surface

**Version:** `0.1.0`

**Directory:** `crates/pcloud-config`

**Manifest:** [`crates/pcloud-config/Cargo.toml`](https://github.com/ezechiel203/pcloud-rs/blob/main/crates/pcloud-config/Cargo.toml)

Typed configuration loader and validator for the pcloud-rs Rust workspace.

## Feature-family profile

**Why it exists.** Give every process one validated, versioned, secure configuration model across platforms and deployment sizes.

**What it is good for.** Profiles, paths, API/TLS settings, vault selection, limits, sync/mount policy, observability, HA, residency, KMS, bandwidth, and upgrades.

**Why it is good at that job.** Schema validation, migrations, permission checks, typed environment overrides, and cross-field invariants reject unsafe combinations early.

# pcloud-supervisor

Multi-account supervisor scaffold (T2.8). Per-account state + IPC routing model.

Part of [pcloud-rs](https://github.com/ezechiel203/pcloud-rs).

## Usage

```toml
[dependencies]
pcloud-supervisor = { version = "0.8.1-beta", registry = "kellnr" }
```

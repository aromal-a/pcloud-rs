# pcloud-plugin-host

Sandboxed plugin host scaffold (T2.5). Capability-bound message-bus model; wasmtime backing tracked for follow-up integration.

Part of [pcloud-rs](https://github.com/ezechiel203/pcloud-rs).

## Usage

```toml
[dependencies]
pcloud-plugin-host = { version = "0.8.1-beta", registry = "kellnr" }
```

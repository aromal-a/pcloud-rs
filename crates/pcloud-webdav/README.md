# pcloud-webdav

Experimental local HTTP/WebDAV subset; no production daemon backend or RFC 4918 compliance claim.

Part of [pcloud-rs](https://github.com/ezechiel203/pcloud-rs).

## Usage

```toml
[dependencies]
pcloud-webdav = { version = "0.8.1-beta", registry = "kellnr" }
```

# pcloud-idp

Enterprise identity-provider (IdP) broker traits for federated login (OIDC, SAML, LDAP). Includes an OIDC Authorization Code + PKCE broker.

Part of [pcloud-rs](https://github.com/ezechiel203/pcloud-rs).

## Usage

```toml
[dependencies]
pcloud-idp = { version = "0.8.1-beta", registry = "kellnr" }
```

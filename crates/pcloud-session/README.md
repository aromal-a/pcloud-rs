# pcloud-session

Session lifecycle, refresh-loop, and auth-vault primitives extracted from pcloud-daemon (P6.1).

Part of [pcloud-rs](https://github.com/ezechiel203/pcloud-rs).

## Usage

```toml
[dependencies]
pcloud-session = { version = "0.8.1-beta", registry = "kellnr" }
```
